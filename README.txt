PROJET KAMBIKILA — VERSION 3 / TABLEAU DE BORD PROFESSIONNEL + TRAVAILLEURS & PAIE

Cette version reprend les données financières déjà intégrées à l'application et ajoute un module de gestion des travailleurs et de la paie.

TRAVAILLEURS PRÉENREGISTRÉS
- Patrick — Tous travaux — 200 000 FC / mois — logé à la ferme — début 01/09/2026
- Martin — Tous travaux — 200 000 FC / mois — logé à la ferme — début 01/09/2026
- Emmanuel — Superviseur — 50 USD / mois — début 01/09/2026
- Jour de paie prévu : le 5 de chaque mois
- Première paie enregistrée comme échéance : 05/10/2026 pour le mois de septembre 2026

PAIE
1. Ouvrir « Travailleurs & paie ».
2. Vérifier le montant et l'échéance.
3. Cliquer « Payer » et choisir la date + le mode de paiement.
4. Une fois validé, le salaire passe à « Payé » et est automatiquement comptabilisé dans les dépenses financières.
5. Cliquer « Bulletin » pour générer le bulletin de paie PDF du salarié payé.

MONTANT MENSUEL DE L'ÉQUIPE
- Patrick : 200 000 FC

EXPORTS
- Financements : PDF, CSV, Excel
- Dépenses : PDF, CSV, Excel
- Devis & activités : PDF, CSV, Excel
- Recettes & ventes : PDF, CSV, Excel
- Paie : CSV et Excel
- Bulletins individuels : PDF

DONNÉES ET STOCKAGE
- Pas de serveur et pas de base de données à installer.
- Les données sont sauvegardées automatiquement dans le navigateur via localStorage.
- Export/import JSON disponible dans la barre latérale.
- La version V3 utilise une nouvelle clé locale et migre automatiquement les données sauvegardées de la V2.

LANCEMENT
- Décompresser le ZIP.
- Ouvrir index.html dans Chrome, Edge ou Firefox.
- Pour activer les exports PDF/Excel, une connexion Internet peut être nécessaire pour charger les bibliothèques CDN.
- Le CSV et le stockage local restent utilisables sans serveur.
